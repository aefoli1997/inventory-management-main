Request Data Flow

User adjusts a filter

The global FilterBar updates shared singleton state in useFilters.js (period, location, category, status).

View requests data

A view calls getCurrentFilters() and passes it to the matching method in api.js.

Axios issues a GET

Filters become query params (warehouse, category, status, month); 'all' values are omitted.

FastAPI filters in memory

The endpoint runs apply_filters() and filter_by_month() over the in-memory lists (months and Q1–Q4 quarters supported).

Pydantic validates the response

Results are serialized against a response_model and returned as JSON.

Vue renders reactively

Raw data lands in refs; computed properties derive metrics and feed custom SVG charts, KPI cards, and tables.
